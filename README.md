# Oversight study

Does an independent AI review help a human catch flawed AI proposals?

**Status: draft 0.1, 25 November 2026. Not registered, not funded, no data collected.**

- [PROTOCOL.md](PROTOCOL.md): the draft protocol.

The study is planned by NEOTOPIA Foundation, a Polish non-profit (KRS 0001280359). It would use the foundation's real operational work, where AI agents draft and one person approves. It would be exploratory, with one overseer and low statistical power.

Before the first run we will register the protocol on a public service with its own timestamp and publish the scripts here. Comments and criticism are welcome in Issues, especially on the design and the flaw types. Please do not post personal data.
